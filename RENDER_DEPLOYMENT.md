# Render Deployment Guide

This guide will help you deploy the FMEA AI application to Render.

## Prerequisites

1. A Render account (sign up at https://render.com)
2. Your code pushed to a Git repository (GitHub, GitLab, or Bitbucket)
3. OpenAI API key (for AI features)

## Deployment Steps

### 1. Backend Deployment

1. **Create a new Web Service on Render:**
   - Go to your Render dashboard
   - Click "New +" → "Web Service"
   - Connect your Git repository

2. **Configure the Backend Service:**
   - **Name:** `fmea-backend`
   - **Environment:** `Docker`
   - **Dockerfile Path:** `./fmea_backend/Dockerfile.prod`
   - **Docker Context:** `./fmea_backend`
   - **Plan:** Starter (or higher)
   - **Region:** Oregon (or your preferred region)

3. **Set Environment Variables:**
   ```
   ENVIRONMENT=production
   CORS_ORIGINS=https://fmea-frontend.onrender.com
   DATABASE_URL=sqlite:////app/db/fmea.db
   SECRET_KEY=<generate-a-secure-random-key>
   OPENAI_API_KEY=<your-openai-api-key>
   ```

4. **Deploy:**
   - Click "Create Web Service"
   - Wait for deployment to complete
   - Note the service URL (e.g., `https://fmea-backend.onrender.com`)

### 2. Frontend Deployment

1. **Create a new Web Service on Render:**
   - Go to your Render dashboard
   - Click "New +" → "Web Service"
   - Connect the same Git repository

2. **Configure the Frontend Service:**
   - **Name:** `fmea-frontend`
   - **Environment:** `Docker`
   - **Dockerfile Path:** `./frontend/Dockerfile.prod`
   - **Docker Context:** `./frontend`
   - **Plan:** Starter (or higher)
   - **Region:** Oregon (or your preferred region)

3. **Set Environment Variables:**
   ```
   VITE_API_BASE_URL=https://fmea-backend.onrender.com
   NODE_ENV=production
   ```

4. **Deploy:**
   - Click "Create Web Service"
   - Wait for deployment to complete
   - Note the service URL (e.g., `https://fmea-frontend.onrender.com`)

### 3. Update CORS Settings

After both services are deployed:

1. **Update Backend CORS:**
   - Go to your backend service settings
   - Update `CORS_ORIGINS` to include your frontend URL:
   ```
   CORS_ORIGINS=https://fmea-frontend.onrender.com
   ```
   - Redeploy the backend service

### 4. Using render.yaml (Alternative Method)

You can also use the provided `render.yaml` file for automated deployment:

1. **Connect Repository:**
   - In Render dashboard, go to "Blueprints"
   - Click "New Blueprint"
   - Connect your repository
   - Select the `render.yaml` file

2. **Configure Environment Variables:**
   - Set `OPENAI_API_KEY` in the environment variables section
   - Render will automatically generate other required variables

3. **Deploy:**
   - Click "Apply" to deploy both services

## Environment Variables Reference

### Backend Variables
- `ENVIRONMENT`: Set to `production`
- `CORS_ORIGINS`: Comma-separated list of allowed origins
- `DATABASE_URL`: SQLite database path
- `SECRET_KEY`: JWT secret key (auto-generated by Render)
- `OPENAI_API_KEY`: Your OpenAI API key

### Frontend Variables
- `VITE_API_BASE_URL`: Backend service URL
- `NODE_ENV`: Set to `production`

## Post-Deployment

1. **Test the Application:**
   - Visit your frontend URL
   - Test user registration/login
   - Create a test project
   - Verify AI suggestions work (if OpenAI key is configured)

2. **Monitor Logs:**
   - Check both service logs in Render dashboard
   - Look for any errors or warnings

3. **Health Checks:**
   - Backend health: `https://your-backend-url.onrender.com/health`
   - Frontend should load without errors

## Troubleshooting

### Common Issues

1. **CORS Errors:**
   - Ensure `CORS_ORIGINS` includes your frontend URL
   - Check that URLs don't have trailing slashes

2. **Database Issues:**
   - SQLite database is created automatically
   - Check logs for database initialization errors

3. **Build Failures:**
   - Check Docker build logs
   - Ensure all dependencies are in requirements.txt
   - Verify Dockerfile paths are correct

4. **Service Not Starting:**
   - Check environment variables
   - Verify health check endpoint is working
   - Check service logs for errors

### Getting Help

- Check Render documentation: https://render.com/docs
- Review service logs in Render dashboard
- Ensure all environment variables are set correctly

## Security Notes

- Never commit API keys to your repository
- Use Render's environment variable system for secrets
- Regularly rotate your SECRET_KEY
- Monitor your OpenAI API usage

## Scaling

- Upgrade to higher plans for better performance
- Consider using PostgreSQL for production databases
- Implement proper logging and monitoring
- Set up automated backups
